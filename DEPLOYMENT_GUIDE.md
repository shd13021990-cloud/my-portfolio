# Shahid Akram — Personal Portfolio Deployment Guide

Yeh portfolio **100% Free** host ho sakti hai **Vercel** ya **Netlify** par baghair kisi monthly kharche kay!

---

## Option 1: Netlify Drop (Sub say asaan — 30 seconds main live)
1. Browser main open karain: **https://app.netlify.com/drop**
2. Apna `D:\My_Portfolio` ka folder pakrain aur wahan drag-and-drop kar dain.
3. 10 second main aap ki website live ho jaye gi aur aap ko ek permanent free link (e.g. `shahidakram.netlify.app`) mil jaye ga!

---

## Option 2: Vercel (Official & Fast)
1. **https://vercel.com** par free account banayain (GitHub ya Email say).
2. **Add New... > Project** par click karain.
3. Agar aap GitHub use kartay hain to yeh folder GitHub repo main push kar kay Vercel say connect karain.
4. Ya phir Vercel CLI say:
   ```bash
   npx vercel
   ```
5. `vercel.json` already configured hai, foran deploy ho jaye ga!
